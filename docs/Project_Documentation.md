## 2. Objective
The objective is to build a Python program that organizes student marks and attendance, calculates useful academic metrics, and presents understandable class, subject, and student-level summaries. It demonstrates Python fundamentals, functions, loops, NumPy, Pandas, and basic data analysis without machine learning.

## 3. Technologies Used
- Python 3.10+
- Pandas for CSV loading, DataFrames, grouping, aggregation, sorting and export
- NumPy for numerical conditions and vectorized pass/fail and attendance calculations
- CSV for storing the input dataset
- `unittest` for basic automated tests

## 4. Dataset Description
The supplied `data/students.csv` contains 20 synthetic sample student records. Fields include Student ID, name, department, marks in Python, Mathematics, Statistics and AI Fundamentals, and attendance percentage. Each subject and attendance value is between 0 and 100. The data is for demonstration and is not real student information.

## 5. Implementation
1. **Load data:** `load_dataset()` reads the CSV into a Pandas DataFrame and checks required columns, empty data, missing values and numeric ranges.
2. **Calculate marks:** `process_student_records()` adds total marks and the mean of the four subject marks.
3. **Assign grades:** `assign_grade()` uses conditional statements to map average marks to a letter grade.
4. **Determine result:** NumPy checks whether every subject mark is at least 40. If any subject is below 40, the student is marked FAIL.
5. **Attendance flag:** Attendance of 75% or more is labelled Eligible; otherwise Low Attendance. This flag is independent of academic pass/fail.
6. **Analyze data:** Pandas calculates class-level statistics, subject averages/highest/lowest/pass counts, department averages and grade distribution. `nlargest()` identifies the top five students.
7. **Export results:** The program writes detailed processed records and a subject summary to the `output/` directory.

## 6. Grading and Result Rules
- Total marks: sum of four subjects, maximum 400.
- Average marks: total marks divided by four, maximum 100.
- Pass: all four subject marks are at least 40.
- Fail: at least one subject mark is below 40.
- Grade bands: A+ (90–100), A (80–89.99), B (70–79.99), C (60–69.99), D (50–59.99), E (40–49.99), F (below 40).
- Attendance flag: Eligible at 75% or above.

These are project-defined rules for this demonstration dataset and should be changed if the instructor provides a different grading policy.
